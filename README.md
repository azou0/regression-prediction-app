# Regression Prediction App

A simple machine learning web application that uses a FastAPI backend to serve predictions from a scikit-learn regression model and an HTML/JavaScript frontend for user interaction.

The backend was built by following a tutorial and uses a regression model trained on a small demonstration dataset. The HTML/JavaScript frontend was developed separately to allow users to enter input values, send requests to the prediction API, and view the returned prediction.

## Technologies Used

- Python
- FastAPI
- Pydantic
- scikit-learn
- Joblib
- Uvicorn
- HTML
- JavaScript
